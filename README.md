# AI-Driven-MS365-CareSupport-Automation


This project is still in progress.
I’m building a small support automation system using Microsoft 365 tools.
The idea is to connect SharePoint, Power Automate, Power Apps and a <b> Copilot Studio Agent </b> to handle support cases in a simple way.

Right now I’m preparing the structure, data model and basic flows.
Later I will add the shared mailbox integration, AI classification using <b> Copilot Studio Workflows </b> and a small Power Apps app for updating ticket status.

More updates soon.
